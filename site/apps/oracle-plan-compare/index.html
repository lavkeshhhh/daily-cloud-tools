How steps are matched

The comparison follows indentation, operation name and object name along each branch. Repeated identical siblings are paired in display order. A different parent or access method can produce both an addition and a removal. Plan IDs are display labels.

The comparison covers estimated rows, optimizer cost, actual rows, starts, buffers and adaptive active state when present. A blank metric is shown as unavailable. Compare execution statistics from equivalent workloads when investigating performance. Optimizer costs are estimates. Oracle execution plan guide
